# La Neuvième Nuit — version jouable dans le navigateur

> Neuf nuits, qu'ils ont dit. Celle-ci est la troisième.

Un jeu de défense narratif : vous tenez la lisière d'un village dahoméen contre les
**Décousus**, des esprits faits de fil défait. Trois gardiens, trois braises, et une nuit
qui finit par un boss — l'**Avaleur de Lune**, qui n'abat pas vos gardiens : il les avale
et prend leur place.

## ▶ Jouer

**<https://frejustedev.github.io/la-neuvieme-nuit/>**

Rien à installer. Le premier chargement fait environ 40 Mo, soyez patient une poignée de
secondes ; ensuite le navigateur le garde en cache.

Fonctionne sur Chrome, Firefox, Edge et Safari récents — cette version est compilée sans
fils d'exécution, elle ne réclame donc aucun réglage de serveur particulier.
Prévu pour un écran d'ordinateur : il n'y a pas encore de commandes tactiles.

## Comment on joue

| | |
|---|---|
| **Ramasser une luciole** | clic dessus — c'est votre seule monnaie, la **lueur** |
| **Poser un gardien** | choisir en bas, puis cliquer une case |
| **Améliorer** | cliquer un gardien déjà posé |
| **But** | garder au moins une des **trois braises** allumées jusqu'à l'aube |

Les trois maisons à gauche sont ce que vous défendez. Chaque esprit qui atteint la lisière
en éteint une. Si l'Avaleur passe, la nuit est perdue sur-le-champ.

Menu → **Options** : volume, français/anglais, ramassage automatique des lucioles, et un
mode **photosensibilité** qui retire clignotements et secousses.

## Un conseil, un seul

Pendant huit vagues, étaler sa défense sur les cinq rangées est la bonne réponse.
Quand l'Avaleur entre, ça devient la mauvaise. Écoutez ce que dit Sunvi.
